# MPE Editor for REAPER — ReaPack Distribution Repository

This repository provides binary releases and automatic updates for the **MPE Curve Editor** native REAPER extension via [ReaPack](https://reapack.com).

## How to Install via ReaPack

### Repository URL

```text
https://raw.githubusercontent.com/externalmethod0-png/mpe-in-reaper-dist/main/index.xml
```

### Installation Steps

1. In REAPER, navigate to:  
   **Extensions -> ReaPack -> Import repositories...**
2. Paste the repository URL above and click **OK**.
3. In REAPER, go to:  
   **Extensions -> ReaPack -> Browse packages**
4. Search for `MPE Editor`, right-click it, and select **Install**, then click **Apply**.
5. **Restart REAPER** (REAPER extensions are loaded on startup).

### Automatic Updates

To check for and install updates at any time, run:  
**Extensions -> ReaPack -> Synchronize packages**  
Then restart REAPER.

## Features

- **Per-Note MPE Curve Editing:** Pitch Bend, Channel Pressure, and Timbre CC74.
- **Normal Mouse Wheel Zoom:** Bare mouse wheel horizontal zoom option without holding Ctrl.
- **Reset All Expressions:** Dedicated action and `Shift + F` shortcut to clear all expression curves for selected notes.
- **Dynamic Grid Sync:** Visual grid instantly adapts to REAPER MIDI Editor grid division and swing changes.
- **Inline Editor Mode:** Attached strip to arrange view items with modulation brushes.
- **Theme & Docker Integration:** Follows REAPER theme colors; supports docking with middle-click tab closure.
